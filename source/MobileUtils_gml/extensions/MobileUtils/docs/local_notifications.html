Local Notifications

This module schedules, cancels and listens for local notifications, and manages notification permission, on Android and iOS.

Functions

The following functions are provided to work with local notifications:

  • mobile_utils_notification_create
  • mobile_utils_notification_create_ext
  • mobile_utils_notification_cancel
  • mobile_utils_notification_set_listener
  • mobile_utils_notification_request_permission
  • mobile_utils_notification_permission_status

Constants

The following constant is used by this module:

  • MobileUtilsNotificationPermission

mobile_utils_notification_create

This function schedules a local notification to be shown after a delay.

The notification fires seconds from now, showing title and message. The data string is an arbitrary payload that is delivered back to your listener when the notification is presented or tapped (see mobile_utils_notification_set_listener). Scheduling a new notification with an identifier that is already pending replaces the previous one.

Note

If seconds is 0 or negative the call does nothing. Notification permission must be granted for the notification to appear (see mobile_utils_notification_request_permission).


Syntax:

gml mobile_utils_notification_create(identifier, seconds, title, message, data)

Argument Type Description
identifier String A unique identifier for this notification (used to cancel or replace it)
seconds Real The delay before the notification fires, in seconds (must be greater than 0)
title String The notification title
message String The notification body text
data String An arbitrary payload string delivered back through the listener


Returns:

N/A


Example:

gml mobile_utils_notification_create("daily_reminder", 5, "Come back!", "Your energy is full.", "reminder"); The code above schedules a notification to appear five seconds from now.

mobile_utils_notification_create_ext

This function schedules a local notification with an image, extending mobile_utils_notification_create.

It behaves exactly like mobile_utils_notification_create but also takes an image_path. On Android the image is shown as the notification's large icon; on iOS it is attached to the notification. The path is used as-is if absolute, otherwise it is resolved relative to the application's storage area; if the file cannot be used, the notification is still scheduled without the image.


Syntax:

gml mobile_utils_notification_create_ext(identifier, seconds, title, message, data, image_path)

Argument Type Description
identifier String A unique identifier for this notification (used to cancel or replace it)
seconds Real The delay before the notification fires, in seconds (must be greater than 0)
title String The notification title
message String The notification body text
data String An arbitrary payload string delivered back through the listener
image_path String The path to an image to show with the notification


Returns:

N/A


Example:

gml // Save a sprite to disk, then schedule a notification that shows it. var _file = "notification_icon.png"; sprite_save(spr_icon, 0, _file); mobile_utils_notification_create_ext("with_icon", 5, "Large Icon!", "Nice, right?", "", _file); The code above schedules a notification that displays an image.

mobile_utils_notification_cancel

This function cancels a pending local notification that was scheduled with mobile_utils_notification_create or mobile_utils_notification_create_ext.

If no notification with the given identifier is pending, the call has no effect.


Syntax:

gml mobile_utils_notification_cancel(identifier)

Argument Type Description
identifier String The identifier of the notification to cancel


Returns:

N/A


Example:

gml mobile_utils_notification_cancel("daily_reminder"); The code above cancels a previously scheduled notification.

mobile_utils_notification_set_listener

This function registers a listener that is called whenever a local notification is presented (while the app is in the foreground) or tapped by the player.

The listener stays registered and may be invoked many times. Notifications that arrive before a listener is registered — for example a tap that cold-starts the app — are queued and delivered as soon as the listener is set.

Note

The image_path member is only populated on Android; on iOS it is always an empty string.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gml mobile_utils_notification_set_listener(callback)

Argument Type Description
callback Function The listener method to call for each presented or tapped notification


Returns:

N/A


Triggers:

Callback

This callback is triggered each time a local notification is presented or tapped.

Key Type Description
identifier String The identifier of the notification
title String The notification title
message String The notification body text
data String The payload string that was supplied when the notification was created
image_path String The image path associated with the notification (Android only; always empty on iOS)


Example:

gml mobile_utils_notification_set_listener(function(_id, _title, _message, _data, _image_path) { show_debug_message($"Notification '{_id}' fired: {_title} - {_message}"); }); The code above registers a listener that logs every notification as it is presented or tapped.

mobile_utils_notification_request_permission

This function requests permission to show notifications, prompting the player if required.

On Android 13+ this triggers the runtime POST_NOTIFICATIONS prompt; on iOS it requests notification authorization. On platforms/versions with no runtime prompt it reports the current effective setting.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gml mobile_utils_notification_request_permission(callback)

Argument Type Description
callback Function The method to call once the permission request resolves


Returns:

N/A


Triggers:

Callback

This callback is triggered when the permission request resolves.

Key Type Description
granted Boolean Whether notification permission is granted
error String The error message (empty when granted is true)


Example:

gml mobile_utils_notification_request_permission(function(_granted, _error) { if (!_granted) show_debug_message("Notifications not granted: " + _error); }); The code above requests notification permission and logs the outcome.

mobile_utils_notification_permission_status

This function queries the current notification permission status without prompting the player.

The status passed to the callback is a member of the MobileUtilsNotificationPermission enumeration.

Note

Provisional and Ephemeral are only ever reported on iOS.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gml mobile_utils_notification_permission_status(callback)

Argument Type Description
callback Function The method to call with the current permission status


Returns:

N/A


Triggers:

Callback

This callback is triggered with the current notification permission status.

Key Type Description
status MobileUtilsNotificationPermission The current notification permission status


Example:

gml mobile_utils_notification_permission_status(function(_status) { if (_status == MobileUtilsNotificationPermission.NotDetermined) { mobile_utils_notification_request_permission(function(_granted, _error) {}); } }); The code above checks the notification permission and requests it only if it has not been decided yet.

MobileUtilsNotificationPermission

This enumeration contains the possible notification permission states reported by mobile_utils_notification_permission_status (and used with mobile_utils_notification_request_permission).

These constants are referenced by the following functions:

  • mobile_utils_notification_permission_status


Member Description
Unknown The permission state could not be determined.
NotDetermined The player has not yet been asked for permission.
Denied Notifications are not permitted.
Authorized Notifications are permitted.
Provisional Notifications are provisionally authorized (iOS only).
Ephemeral Notifications are ephemerally authorized, e.g. for an App Clip (iOS only).
