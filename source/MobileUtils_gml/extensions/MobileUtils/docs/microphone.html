Microphone

This module requests and queries the microphone (audio recording) permission on Android and iOS.

Functions

The following functions are provided to work with microphone permission:

  • mobile_utils_mic_request
  • mobile_utils_mic_check

Constants

The following constant is used by this module:

  • MobileUtilsMicPermission


Back To Top

mobile_utils_mic_request

This function requests the microphone (audio recording) permission, prompting the player if required.

On Android this triggers the runtime RECORD_AUDIO prompt; on iOS it triggers the system microphone access prompt. If permission has already been granted or denied, the call is a harmless no-op — the OS answers immediately without showing a dialog again.

Note

This function does not report the outcome directly. Call mobile_utils_mic_check afterward (for example on the next room step or when the app resumes) to read the result.


Syntax:

gml mobile_utils_mic_request()


Returns:

N/A


Example:

gml mobile_utils_mic_request(); The code above prompts the player for microphone access if it has not been decided yet.

mobile_utils_mic_check

This function queries the current microphone permission status without prompting the player.

The status passed to the callback is a member of the MobileUtilsMicPermission enumeration.

Note

On Android, NotDetermined covers both "never asked" and "permanently denied" (Don't ask again) — the OS does not expose a way to tell these apart other than attempting the request via mobile_utils_mic_request and checking again.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gml mobile_utils_mic_check(callback)

Argument Type Description
callback Function The method to call with the current permission status


Returns:

N/A


Triggers:

Callback

This callback is triggered with the current microphone permission status.

Key Type Description
status MobileUtilsMicPermission The current microphone permission status


Example:

gml mobile_utils_mic_check(function(_status) { if (_status == MobileUtilsMicPermission.NotDetermined) { mobile_utils_mic_request(); } }); The code above checks the microphone permission and requests it only if it has not been decided yet.

MobileUtilsMicPermission

This enumeration contains the possible microphone permission states reported by mobile_utils_mic_check.

These constants are referenced by the following functions:

  • mobile_utils_mic_check


Member Description
Unknown The permission state could not be determined (for example, no activity is available).
NotDetermined The player has not yet been asked for permission (Android: this also covers a permanent "Don't ask again" denial).
Denied Microphone access is not permitted.
Granted Microphone access is permitted.
