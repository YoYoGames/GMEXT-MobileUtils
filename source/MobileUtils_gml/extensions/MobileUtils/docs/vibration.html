Device Vibration

This module triggers device vibration and haptic feedback on Android and iOS.

The predefined effects use platform-specific enumerations that overlap numerically — always select the effect with the enum member that matches the running platform (see mobile_utils_vibrate_predefined).

Functions

The following functions are provided to work with vibration:

  • mobile_utils_vibrate_is_available
  • mobile_utils_vibrate_predefined
  • mobile_utils_vibrate_shot

Constants

The following constants are used by this module:

  • MobileUtilsVibrationAvailability
  • MobileUtilsAndroidVibrationKind
  • MobileUtilsIOSVibrationKind

mobile_utils_vibrate_is_available

This function reports what level of vibration / haptic support the device has.

The returned value is a member of the MobileUtilsVibrationAvailability enumeration. Call this before triggering a vibration to decide whether it will have any effect.

Note

HapticEngine is only ever returned on iOS (devices with a Core Haptics engine). Android reports either None or Basic.


Syntax:

gml mobile_utils_vibrate_is_available()


Returns:

Real

The device's vibration capability


Example:

gml if (mobile_utils_vibrate_is_available() == MobileUtilsVibrationAvailability.None) { show_debug_message("Vibration is not available."); } The code above checks whether the device can vibrate at all.

mobile_utils_vibrate_predefined

This function plays one of the device's predefined haptic effects.

The kind is a value from the platform-specific enumeration for the device you are running on: use a MobileUtilsAndroidVibrationKind member on Android and a MobileUtilsIOSVibrationKind member on iOS. Branch on os_type to choose the correct one.

Warning

The two enumerations share the same low integers with different meanings (for example 2 is Tick on Android but ImpactHeavy on iOS), and some values exist on only one platform. Never pass a raw integer or an Android kind on iOS (or vice versa) — always use the enum member that matches the running platform, otherwise you get the wrong effect or a false return.


Syntax:

gml mobile_utils_vibrate_predefined(kind)

Argument Type Description
kind Real The predefined effect to play — a MobileUtilsAndroidVibrationKind member on Android or a MobileUtilsIOSVibrationKind member on iOS


Returns:

Boolean

true if the effect was played, false if the device cannot play it or the kind is not valid for the platform


Example:

gml if (mobile_utils_vibrate_is_available()) { var _kind = (os_type == os_ios) ? MobileUtilsIOSVibrationKind.ImpactMedium : MobileUtilsAndroidVibrationKind.Click; mobile_utils_vibrate_predefined(_kind); } The code above plays a predefined haptic using the enum member appropriate to the current platform.

mobile_utils_vibrate_shot

This function plays a single vibration of the given duration.

On iOS 13 and later this is a continuous Core Haptics event of the requested length; on older iOS it falls back to a predefined impact. On Android it is a one-shot vibration of the requested duration.


Syntax:

gml mobile_utils_vibrate_shot(milliseconds)

Argument Type Description
milliseconds Real The vibration duration in milliseconds (must be greater than 0)


Returns:

Boolean

true if the vibration was played, false on an invalid duration or an incapable device


Example:

gml if (mobile_utils_vibrate_is_available()) { mobile_utils_vibrate_shot(1000); } The code above plays a one-second vibration when the device supports it.

MobileUtilsVibrationAvailability

This enumeration contains the vibration capability levels returned by mobile_utils_vibrate_is_available.


Member Description
None The device has no vibration hardware.
Basic The device supports basic vibration.
HapticEngine The device has a dedicated haptic engine (iOS only).

MobileUtilsAndroidVibrationKind

This enumeration contains the predefined haptic effects available on Android, for use with mobile_utils_vibrate_predefined.


Member Description
Click A single click effect.
DoubleClick A double click effect.
Tick A light tick effect.
HeavyClick A heavy click effect.

MobileUtilsIOSVibrationKind

This enumeration contains the predefined haptic effects available on iOS, for use with mobile_utils_vibrate_predefined.


Member Description
ImpactLight A light impact feedback.
ImpactMedium A medium impact feedback.
ImpactHeavy A heavy impact feedback.
ImpactRigid A rigid impact feedback (iOS 13+).
ImpactSoft A soft impact feedback (iOS 13+).
Selection A selection-changed feedback.
NotificationWarning A warning notification feedback.
NotificationSuccess A success notification feedback.
NotificationError An error notification feedback.
