Push Notifications (APNs)

This module registers for Apple Push Notifications and exposes the device token. It is iOS-only and experimental — the functions do nothing on Android, so guard calls with os_type == os_ios.

Functions

The following functions are provided to work with push notifications:

  • mobile_utils_apn_register
  • mobile_utils_apn_get_token

mobile_utils_apn_register

This function registers the device for Apple Push Notifications (APNs) and returns the resulting device token.

Registration requests notification authorization and then asks Apple for a device token. Once obtained the token is cached for the rest of the process, so subsequent calls return it immediately. Send the token to your push backend so it can address this device.

Note

This is an iOS-only, experimental feature. On Android the function is not implemented and does nothing; guard your call with os_type == os_ios. Set the APS Environment extension option to production for release builds (see Extension Options).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gml mobile_utils_apn_register(callback)

Argument Type Description
callback Function The method to call once registration finishes


Returns:

N/A


Triggers:

Callback

This callback is triggered when APNs registration finishes.

Key Type Description
success Boolean Whether a device token was obtained
token String The APNs device token as a hex string (empty when success is false)
error String The error message (empty when success is true)


Example:

gml if (os_type != os_ios) return; mobile_utils_apn_register(function(_success, _token, _error) { if (_success) show_debug_message("Device token: " + _token); else show_debug_message("APNs registration failed: " + _error); }); The code above registers for push notifications on iOS and logs the device token.

mobile_utils_apn_get_token

This function returns the APNs device token obtained by mobile_utils_apn_register earlier in this session.

Note

This is an iOS-only, experimental feature. It returns an empty string if registration has not completed (or on Android).


Syntax:

gml mobile_utils_apn_get_token()


Returns:

String

The cached APNs device token, or an empty string if none is available


Example:

gml var _token = mobile_utils_apn_get_token(); if (_token != "") show_debug_message("Token: " + _token); The code above reads the cached push token and uses it if one is available.
